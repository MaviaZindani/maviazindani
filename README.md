### About

Mobile developer with 4 years of experience taking applications from first commit to production release. I work natively in **Kotlin** and cross-platform in **Flutter**, structuring codebases around **Clean Architecture** and **BLoC** so features stay testable as they grow. When a product needs backend work I build it in **Node.js / Express** or **Laravel**.

- 📱 Multiple apps live on **Google Play** and the **App Store**, released and maintained end to end
- 🔌 Integration-heavy work: REST APIs, Socket.IO, Stripe, Google Maps, Agora, Firebase, Gemini API

- 📍 Based in Karachi, Pakistan · open to remote and on-site roles
